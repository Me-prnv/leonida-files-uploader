Uses YouTube API Services

Leonida Files Uploader is a private, single-user tool that uploads videos to the owner's own YouTube channels, Leonida Files and Vice Clips Daily, using the YouTube Data API.

What it does

  • The channel owner renders videos on his own computer.
  • He reviews each video and approves it.
  • Only approved videos are uploaded to his own channels with the youtube.upload permission, with title, description, thumbnail and publish time.

Who can use it

Only the channel owner. The tool is not offered to the public, has no sign-up, and does not access any other person's YouTube account or data.
